# suckless

Personal builds of [suckless](https://suckless.org/philosophy/) software.

- [dmenu](dmenu/README.md) — dynamic menu
- [dwm](dwm/README.md) — dynamic window manager
- [dwmblocks](dwmblocks/README.md) — async status bar
- [quark](quark/README.md) — HTTP GET/HEAD server
- [scron](scron/README.md) — cron daemon
- [slock](slock/README.md) — X display locker
- [st](st/README.md) — simple terminal
- [surf](surf/README.txt) — WebKit browser
- [tabbed](tabbed/README.md) — tabbed X interface
- [xnap](xnap/README.md) — screenshot utility
